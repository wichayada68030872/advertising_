# โครงงานวิเคราะห์ข้อมูลด้วย Python: ชุดข้อมูล Advertising

วิเคราะห์ความสัมพันธ์ระหว่างงบโฆษณาผ่านสื่อ 3 ช่องทาง (TV, Radio, Newspaper) กับยอดขาย (Sales) ด้วยสถิติเชิงพรรณนา การตรวจหาค่าผิดปกติ การสร้างกราฟ และการคำนวณค่าสหสัมพันธ์

## ชุดข้อมูล

ไฟล์ `Advertising.csv` มี 200 แถว (200 ตลาด) ไม่มีค่าสูญหายและไม่มีแถวซ้ำ

| ตัวแปร | ความหมาย |
|---|---|
| TV | งบโฆษณาทางโทรทัศน์ |
| Radio | งบโฆษณาทางวิทยุ |
| Newspaper | งบโฆษณาทางหนังสือพิมพ์ |
| Sales | ยอดขาย |

หมายเหตุ: ไฟล์มีคอลัมน์ `Unnamed: 0` ซึ่งเป็นเลขลำดับ โค้ดจะตัดทิ้งก่อนวิเคราะห์

แหล่งที่มา:(https://www.kaggle.com/datasets/tawfikelmetwally/advertising-dataset/data?utm_source=chatgpt.com)

## สิ่งที่วิเคราะห์

1. ตรวจสอบข้อมูลเบื้องต้น (ขนาด ชนิดข้อมูล ค่าสูญหาย แถวซ้ำ)
2. สถิติเชิงพรรณนา: ค่าเฉลี่ย ส่วนเบี่ยงเบนมาตรฐาน (ddof=1) ต่ำสุด มัธยฐาน สูงสุด
3. ตรวจหาค่าผิดปกติด้วยกฎ 1.5 × IQR
4. กราฟ: ฮิสโตแกรม แผนภาพกล่อง และกราฟการกระจายระหว่างงบโฆษณากับ Sales
5. ค่าสหสัมพันธ์ระหว่างตัวแปร

## ผลเบื้องต้น

| ตัวแปร | ค่าเฉลี่ย | ส.บ.ม. |
|---|---|---|
| TV | 147.04 | 85.85 |
| Radio | 23.26 | 14.85 |
| Newspaper | 30.55 | 21.78 |
| Sales | 14.02 | 5.22 |

สหสัมพันธ์กับ Sales: TV 0.782, Radio 0.576, Newspaper 0.228 และพบค่าผิดปกติเฉพาะ Newspaper จำนวน 2 ค่า

## วิธีรัน

1. ติดตั้ง Python และ library ที่ใช้: `pip install numpy pandas matplotlib jupyter`
2. ดาวน์โหลดไฟล์ทั้งหมดไว้ในโฟลเดอร์เดียวกัน
3. เปิดโฟลเดอร์ใน VS Code แล้วเปิด `Advertising_analysis.ipynb`
4. เลือก Kernel ของ Python แล้วกด **Run All**
